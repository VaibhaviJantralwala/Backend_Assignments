Task 2: Create Single Field Index and Compare Query Time
Before Creating Index
db.restaurants.find({
    cuisine: "Italian"
}).explain("executionStats")

Create Index
db.restaurants.createIndex({
    cuisine: 1
})

After Creating Index
db.restaurants.find({
    cuisine: "Italian"
}).explain("executionStats")

Task 3: Create Compound Index
db.restaurants.createIndex({
    cuisine: 1,
    location: 1
})

Query:

db.restaurants.find({
    cuisine: "Chinese",
    location: "Ahmedabad"
})

Check whether index is used:

db.restaurants.find({
    cuisine: "Chinese",
    location: "Ahmedabad"
}).explain("executionStats")

In the output, look for:

IXSCAN

If you see IXSCAN, the compound index is being used.

Task 4: Drop the Cuisine Index

List indexes:

db.restaurants.getIndexes()

Drop the single-field index:

db.restaurants.dropIndex({
    cuisine: 1
})

Run the query again:

db.restaurants.find({
    cuisine: "Italian"
}).explain("executionStats")

Task 5: Query to Fetch Top 5 Pizza Restaurants in Surat
db.restaurants.find(
    {
        cuisine: "Pizza",
        location: "Surat"
    }
)
.sort({
    rating: -1
})
.limit(5)
